考前公式速查

环节 公式 适用与提醒
二极管恒压降 $I_D=\dfrac{V_{DD}-U_D}{R}$ 先判断导通；硅管默认约 0.7 V。
三极管电流 $I_E=I_B+I_C,\quad \beta=\dfrac{I_C}{I_B}$ 放大区使用；必须核对实际偏置。
基本共射 Q 点 $I_{BQ}=\dfrac{V_{CC}-U_{BEQ}}{R_b}$ 随后求 $I_{CQ}=\beta I_{BQ}$ 并验算 $U_{CEQ}$。
输入电阻参数 $r_{be}=r_{bb'}+(1+\beta)\dfrac{U_T}{I_{EQ}}$ $U_T\approx26$ mV；必须使用静态 $I_{EQ}$。
共射电压增益 $\dot A_u=-\dfrac{\beta R_L'}{r_{be}}$ $R_L'=R_c\parallel R_L$；负号表示反相。
源电压增益 $\dot A_{us}=\dfrac{R_i}{R_i+R_s}\dot A_u$ 先求出放大电路输入电阻 $R_i$。
发射极电阻 $\dot A_u\approx-\dfrac{\beta R_L'}{r_{be}+(1+\beta)R_e}$ 适用于 $R_e$ 未被旁路时的近似分析。
RC 截止频率 $f_c=\dfrac{1}{2\pi RC}$ 低通上限、高通下限均用此式辨型。
分贝 $A(\mathrm{dB})=20\lg|A|$ 幅值乘 $1/\sqrt2$ 对应约 −3 dB。
密勒等效电容 $C_i\approx C_\pi+(1+|K|)C_\mu$ 高频共射分析；$K$ 为跨接电容两端电压比。
多级增益 $\dot A_u=\prod_i\dot A_{ui},\quad \varphi=\sum_i\varphi_i$ 复数增益相乘，分贝和相位相加。
多级带宽 $\dfrac1{f_H}\approx1.1\sqrt{\sum_i\dfrac1{f_{Hi}^2}}$ 级数越多，总通频带通常越窄。
甲类功放 $P_{omax}=\dfrac{V_{CC}I_{CQ}}4,\quad \eta_{\max}=25\%$ 静态 Q 点在负载线中点；最大管耗出现在无交流输入时。
OTL 乙类最大输出 $P_{omax}=\dfrac{V_{CC}^2}{8R_L},\quad \eta_{\max}\approx78.5\%$ 单电源、有输出电容；输出电压幅度约为 $V_{CC}/2$。
OCL 互补对称电路的最大功率和电源最大功率 $P_{omax}=\dfrac{V_{CC}^2}{2R_L},\quad P_{V\max}=\dfrac{2V_{CC}^2}{\pi R_L}$ 双电源、负载直连；忽略饱和压降时 $U_{om}\approx V_{CC}$。
复合管 $\beta\approx\beta_1\beta_2,\quad r_{be}\approx r_{be1}+(1+\beta_1)r_{be2}$ 扩大电流驱动能力；谁直接接出等效基极，谁就是前管，复合管类型与前管相同。

ANSWER PROTOCOL

五类题的落笔顺序

不确定时先写“判断依据—所用模型—计算结果—合理性检查”，过程本身就能拿分。

01 · 二极管

先断开，再验状态

  1. 暂时将所有二极管视为开路。
  2. 求阳极与阴极电位差；多个二极管同时可能导通时，先找正偏最大者。
  3. 理想管用短路/开路；恒压降管导通后锁定端电压。
  4. 回代检查：导通则电流非负，截止则端电压不高于导通阈值。
02 · 静态工作点

先电容开路，再求 Q

  1. 画直流通路，忽略交流源。
  2. 由基极回路求 $I_{BQ}$，再求 $I_{CQ}$ 与 $U_{CEQ}$。
  3. 检查 $U_{CEQ}>U_{CES}$；若接近电源或零，分别怀疑截止/饱和。
  4. 用 $I_{EQ}\approx I_{CQ}$ 计算 $r_{be}$。
03 · 小信号

先置零，再等效

  1. 画交流通路：耦合电容短路，直流电压源接地。
  2. 将三极管替换为 $r_{be}$ 与受控电流源 $\beta i_b$。
  3. 标清 $u_i$、$u_o$ 参考方向，输出端先求并联电阻。
  4. 由定义求 $A_u$、$R_i=u_i/i_i$、$R_o=u_o/i_o$，最后检查符号与量纲。
04 · 频率响应

先分频段，再画 Bode

  1. 中频段求 $A_{um}$，作为 Bode 图的水平基准。
  2. 低频找串联耦合电容，高频找结电容与密勒电容。
  3. 幅频以 ±20 dB/十倍频画折线，转折点 −3 dB；相频每项贡献至多 90°。
  4. 多级时增益乘、分贝加、相位加，通频带变窄。
05 · 功率放大

先定结构，再算功率

  1. 单电源且有输出电容先判为 OTL，双电源且负载直连先判为 OCL。
  2. 由输出中点电压确定最大电压摆幅：OTL 约为 $V_{CC}/2$，OCL 约为 $V_{CC}$。
  3. 依次计算 $P_{omax}$、$P_V$、$\eta$ 和每只管子的 $P_T$，再与 $P_{CM}$ 比较。
  4. 纯乙类检查交越失真；甲乙类检查静态偏置、热稳定和偏置支路故障。
