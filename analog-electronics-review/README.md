# 模拟电子技术互动复习站

这是一份可直接打开的模电复习闭环，内容依据六张课堂与教材笔记图片整理，聚焦已经讲到的三章：

1. 半导体器件
2. 放大电路基本原理
3. 放大电路频率响应

本版完成的是现有六张资料所对应的三章，不把教师尚未讲授的后续章节擅自补入。

## 功能

- 章节默认折叠，点击后展开知识点。
- 知识点按“概念、公式、器件特性、分析与判别、电路应用、例题、易错”分类。
- 支持关键词搜索和类型筛选。
- 每个知识点可以标记“已掌握”，进度保存在浏览器。
- 18 道按章节筛选的通关自测，答题后即时显示解析，并生成章节正确率。
- 12 组公式速查和二极管、Q 点、小信号、频率响应四类题的解题流程。
- 补充了折线模型、二极管小信号电阻、稳压管限流电阻计算、共射完整算例和 Bode 例题。
- 照片中的电路图、波形、三极管结构和 Bode 图已切分为 21 张图片，支持点击放大。
- 公式使用离线 KaTeX 渲染，不需要外网。
- 桌面和手机宽度均可使用。
- 支持打印，打印时保留知识卡、公式表和解题流程。

## 查看

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\view.ps1
```

默认地址：`http://127.0.0.1:8766/`

整个目录可以直接部署到 GitHub Pages 或其他静态网站托管服务。
