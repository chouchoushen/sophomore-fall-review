# 模拟电子技术互动复习站

这是一份可直接打开的模电复习闭环，内容依据课堂与教材笔记图片整理，现包含四章：

1. 半导体器件
2. 放大电路基本原理
3. 放大电路频率响应
4. 功率放大电路

半导体器件章依据新增的 12 张课堂图片更新，覆盖二极管伏安特性、静态模型与图解法、整流/限幅/钳位、稳压管计算，以及三极管载流子运动、输出特性和安全工作区。

功率放大电路章依据新增的 13 张图片整理，包含甲类功放分析、OTL/OCL 互补对称电路、交越失真、例题和复合互补管。原始总结图保留在章末，其余例题与电路图与对应知识卡放在一起。

## 功能

- 章节默认折叠，点击后展开知识点。
- 知识点按“概念、公式、器件特性、分析与判别、电路应用、例题、易错”分类。
- 支持关键词搜索和类型筛选。
- 每个知识点可以标记“已掌握”，进度保存在浏览器。
- 24 道按章节筛选的通关自测，答题后即时显示解析，并生成章节正确率。
- 16 组公式速查，以及二极管、Q 点、小信号、频率响应和功率放大五类题的解题流程。
- 补充了折线模型、二极管小信号电阻、稳压管限流电阻计算、共射完整算例和 Bode 例题。
- 照片中的电路图、波形、三极管结构、Bode 图及功率放大章节图片共 40 张，支持点击放大。
- 公式使用离线 KaTeX 渲染，不需要外网。
- 桌面和手机宽度均可使用。
- 支持打印，打印时保留知识卡、公式表和解题流程。
