# Python 3 学习路线

把 `python电子书(1)` 中的资料重组成一套原创、循序渐进的 Python 3 学习网站。

## 课程结构

1. 起步、运行与报错阅读
2. 变量、基本类型与表达式
3. 字符串
4. 列表与元组
5. 字典与集合
6. 条件与循环
7. 函数、作用域与类型标注
8. 文件、路径、JSON 与 CSV
9. 异常、模块、虚拟环境与依赖
10. 面向对象
11. 迭代器、生成器、装饰器与上下文管理器
12. 命令行练习、词频统计、网络请求、爬虫与 Flask 项目

网站包含按章节折叠的知识卡、内容搜索、类型筛选、代码复制、随堂判断和本地学习进度。
