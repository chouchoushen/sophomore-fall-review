# 概率论互动复习站

一个只包含概率论内容的静态学习网站。知识点、课堂例题和结构图按学习顺序组织，公式、例题与图示保存在同一知识卡中。

## 内容结构

1. 随机事件与概率
   - 随机试验、样本空间、事件关系与运算
   - 频率、公理化定义、基本性质
   - 古典概型、排列组合、几何概型
   - 条件概率、乘法公式、全概率、贝叶斯公式
   - 事件独立性与伯努利概型
2. 随机变量及其分布
   - 随机变量、分布函数、概率分布律和概率密度
   - 0–1、二项、泊松、几何、超几何分布
   - 均匀、指数、正态与标准正态分布
   - 随机变量函数的分布
3. 多维随机变量及其分布
   - 二维随机变量和联合分布
   - 联合分布函数、联合概率分布与联合密度
   - 边缘分布、条件分布
   - 二维均匀、二维正态
   - 随机变量独立性与二维函数分布补充

## 交互

- 章节默认折叠，点击章节标题展开知识点。
- 支持按“定义、公式、性质、判定、例题、易错”筛选。
- 支持关键词搜索，并自动展开包含结果的章节。
- 每个知识点可以标记为“已掌握”，进度保存在浏览器 `localStorage`。
- 例题默认折叠，课堂解法与相关结构图放在同一知识卡中。
- 不保留原始拍摄图片；分布图、区域图和事件树均使用可缩放的 SVG 重绘。
- 公式使用离线 KaTeX 渲染，不依赖外部 CDN。

## 手机笔记照片对应关系

带有“照片笔记”来源标识的卡片直接整理自新增的三张笔记图片：

- 二维随机变量性质 → 联合分布函数的性质
- 离散型二维随机变量概率分布分布列 → 离散型二维随机变量联合分布律
- 连续型二维随机变量例题 → 联合概率密度
- 边缘概率函数例题 → 离散情形边缘分布
- 边缘概率密度例题 → 连续情形边缘分布
- 离散型随机变量表达方式 → 离散型概率分布律
- 连续型随机变量例题 → 分布函数与概率密度
- 正态分布定义、标准正态分布 → 对应连续型分布知识卡
- 一维随机变量函数的密度函数、密度函数计算 → 随机变量函数分布
- 条件概率 → 多事件乘法公式
- 全概率公式与贝叶斯公式 → 工厂次品来源例题

## 本地查看

双击或运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\view.ps1
```

脚本会在 `http://127.0.0.1:8765/` 启动静态服务器并打开浏览器。

## 部署

整个目录可以直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态 Web 服务器。网站没有后端，也不依赖外部 CDN。
