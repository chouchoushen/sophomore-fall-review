PROBLEM PROTOCOL

先看对称性，再决定写哪一个积分

静电场题不是从公式表里猜公式，而是先判断场源、对称性和题目要求的“场、势、能”中的哪一个。

  1. 01 选择场源模型

    点、线、面、球、圆环或导体；先确认有限/无限、均匀/非均匀。

  2. 02 判断对称性

    球、轴、面对称决定高斯面；不够对称时回到矢量积分与分量抵消。

  3. 03 求 E、D 或 V

    求通量用高斯定理，求电势用路径积分；方向、参考零点和符号同时确定。

  4. 04 回到边界验算

    检查内部 E、导体表面方向、介质边界和单位，最后再看能量或电容。

FORMULA SHEET

静电场公式速查

公式的右栏比公式本身更重要：有限长、无限大、球内外与介质是否填满都会改变结论。

环节公式适用与提醒
库仑定律 $F=\dfrac{1}{4\pi\varepsilon_0}\dfrac{|q_1q_2|}{r^2}$ 真空中点电荷；方向要另行判断。
点电荷电场 $E=\dfrac{Q}{4\pi\varepsilon_0r^2}$ 正电荷向外，负电荷向内。
高斯定理 $\oint\vec E\cdot\mathrm d\vec S=\dfrac{Q_{\rm in}}{\varepsilon_0}$ 只求通量时无需对称；解 $E$ 时必须利用对称性。
无限长线 $E=\dfrac{\lambda}{2\pi\varepsilon_0r}$ 线近似无限长，观察点远离端点。
无限大平面 $E=\dfrac{\sigma}{2\varepsilon_0}$ 两侧场强大小相同、方向相反。
有介质高斯 $\oint\vec D\cdot\mathrm d\vec S=Q_{\rm free,\,in}$ 右端只算自由电荷，不含束缚电荷。
导体表面 $E=\dfrac{\sigma}{\varepsilon_0}$ 静电平衡，电场垂直导体表面。
电势积分 $V_A=-\displaystyle\int_{\infty}^{A}\vec E\cdot\mathrm d\vec l$ 无穷长/无限大模型不能默认取无穷远为零。
平行板电容 $C=\dfrac{\varepsilon S}{d}$ 忽略边缘效应，介质完全填满板间场区。
圆柱形电容 $C=\dfrac{2\pi\varepsilon L}{\ln(R_2/R_1)}$ 长度远大于半径差，内外半径满足 $R_2>R_1$。
球形电容 $C=\dfrac{4\pi\varepsilon R_1R_2}{R_2-R_1}$ 孤立球取 $R_2\to\infty$，得 $4\pi\varepsilon R_1$。
串联电容 $\dfrac1{C_{\rm eq}}=\sum_i\dfrac1{C_i}$ 串联电荷相同，等效电容小于任一电容。
电场能量密度 $w_e=\dfrac12\varepsilon E^2$ 线性各向同性介质；非均匀场需积分。

ANSWER PROTOCOL

四类题的落笔顺序

把“电荷分布—对称性—场/势—边界条件”写完整，通常比只写最终公式更稳。

01 · 场强积分

先分解，再积分

  1. 标出场源电荷元 $\mathrm dq$ 和从电荷元指向场点的单位矢量。
  2. 先用对称性判断哪些分量两两抵消。
  3. 只对保留下来的分量积分，写明积分变量与上下限。
  4. 用极限情形检查：无限长线、圆环中心、远处点电荷。
02 · 高斯定理

先找对称，再选面

  1. 球对称选同心球面；轴对称选同轴圆柱；面对称选对称柱/盒。
  2. 只计算有通量的面，明确面积矢量指向外侧。
  3. 求 $Q_{\rm in}$ 或 $Q_{\rm free,in}$，再解 $E$ 或 $D$。
  4. 检查分区结果在边界处是否连续或按面电荷发生跃变。
03 · 电势

先定零点，再选路径

  1. 有限带电体通常取无穷远为零；无限长线/面要另设零点。
  2. 沿最方便积分的方向从零点积到目标点。
  3. 电势是标量，直接把各源的电势代数相加。
  4. 用 $E=-\nabla V$ 或 $U=Ed$ 检查方向与数量级。
04 · 电容

先求场和电压，再定义 C

  1. 按几何对称性求两导体之间的 $E(r)$。
  2. 从正极板积分到负极板求 $U$。
  3. 代入 $C=Q/U$，消去 $Q$ 或 $\sigma$。
  4. 明确介质是否填满；再判断电源是否连接，决定固定 $Q$ 还是固定 $U$。
