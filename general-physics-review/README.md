# 普通物理学互动复习站

独立于模电网站的普通物理学复习页面，内容依据用户提供的笔记、教材与课堂图片整理，目前包含四章：

1. 静电场：电荷、库仑定律、电场、高斯定理、典型对称场、电势与等势面。
2. 导体与电介质：静电平衡、空腔导体、静电屏蔽、介质极化、电位移与有介质高斯定理。
3. 电容与电场能量：电容定义、三种典型电容器、串并联、介质插入和能量密度。
4. 恒定磁场：电流与毕奥－萨伐尔定律、磁通与安培环路定理、洛伦兹力与安培力、磁矩、磁介质与磁场强度。

## 功能

- 4 章、99 个知识点，16 个主题。
- 支持关键词搜索、类型筛选、章节折叠和“已掌握”进度保存。
- 26 道通关自测，含即时解析和章节正确率。
- 23 组公式速查，以及场强积分、高斯定理、电势、电容、恒定磁场五类题的解题流程。
- 28 张教材例题、课堂推导与图示已整理到对应知识点卡片中，支持点击放大。
- 高斯定理、有限长直线、圆环电势与电场、带电球面电势、三类电容器、有限长导线、圆电流、安培环路和磁介质例题均与相关公式同卡展示。
- 公式使用本地 KaTeX 渲染，不需要联网。
- 支持桌面、手机和打印布局。
