# 普通物理学互动复习站

独立于模电网站的普通物理学复习页面，内容依据用户提供的四份笔记与课堂图片整理，聚焦已经出现的三部分：

1. 静电场：电荷、库仑定律、电场、高斯定理、典型对称场、电势与等势面。
2. 导体与电介质：静电平衡、空腔导体、静电屏蔽、介质极化、电位移与有介质高斯定理。
3. 电容与电场能量：电容定义、三种典型电容器、串并联、介质插入和能量密度。

## 功能

- 3 章、71 个知识点，12 个主题。
- 支持关键词搜索、类型筛选、章节折叠和“已掌握”进度保存。
- 18 道通关自测，每章 6 题，含即时解析和章节正确率。
- 13 组公式速查，以及场强积分、高斯定理、电势、电容四类题的解题流程。
- 16 张例题与图示已拆分并直接放在对应知识点卡片中，支持点击放大。
- 高斯定理、有限长直线、圆环电势与电场、带电球面电势和三类电容器例题均与相关公式同卡展示。
- 公式使用本地 KaTeX 渲染，不需要联网。
- 支持桌面、手机和打印布局。

## 查看

