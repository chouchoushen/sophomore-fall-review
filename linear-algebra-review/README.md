# 线性代数复习站

本站整理排列、逆序数、`n` 阶行列式、行列式性质、按行（列）展开、拉普拉斯定理、克莱姆法则，以及矩阵概念、矩阵运算、逆矩阵、分块矩阵、初等变换、矩阵的秩和线性方程组。

## 内容结构

1. 第一章：行列式
   - 1.1 排列与逆序数
   - 1.2 `n` 阶行列式的定义
   - 1.3 行列式的性质
   - 1.4 按行（列）展开
   - 1.5 克莱姆法则
2. 第二章：矩阵
   - 2.1 矩阵的概念与特殊矩阵
   - 2.2 矩阵的运算
   - 2.3 逆矩阵
   - 2.4 分块矩阵
3. 第三章：矩阵的初等变换与线性方程组
   - 3.1 矩阵的初等变换
   - 3.2 初等矩阵与矩阵化简
   - 3.3 矩阵的秩
   - 3.4 线性方程组的解

页面按“第一章、第二章、第三章”整合为大章；`1.1`、`2.1`、`3.1` 等只在展开大章后作为可折叠小节出现。
