# 线性代数期中复习站

本站整理排列、逆序数、`n` 阶行列式、行列式性质、按行（列）展开、拉普拉斯定理与克莱姆法则。

## 内容结构

1. 排列与逆序数
   - `n` 阶排列、标准排列与排列总数
   - 逆序、逆序数与奇偶排列
   - 对换、相邻对换及其奇偶性变化
2. `n` 阶行列式的定义
   - 二阶与三阶行列式
   - 对角线法则
   - 置换定义、三角行列式与对角/副对角行列式
3. 行列式的性质
   - 转置不变、换行变号
   - 提取公因子与比例行判定
   - 可加性、倍加变换与化三角计算
4. 按行（列）展开
   - 余子式与代数余子式
   - 按行/列展开与异行余子式之和
   - 范德蒙德行列式、拉普拉斯定理与分块行列式
5. 克莱姆法则
   - 唯一解公式与 `D_i` 的构造
   - 齐次方程组非零解条件
   - 含参数与多变量综合例题
