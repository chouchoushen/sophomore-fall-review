# 数字电子技术互动复习站

独立于模电、普通物理和数学物理方法网站的组合逻辑复习页面，依据用户提供的五份笔记与课堂图片整理：

1. 数制与逻辑代数：进制转换、逻辑运算、布尔恒等式、最小项、最大项和卡诺图。
2. 组合逻辑分析与设计：逻辑门、分析流程、设计流程、二进制算术、补码和加法器。
3. 常用组合逻辑器件：编码器、译码器、数据选择器、分配器、ROM、校验器、比较器和竞争冒险。

## 功能

- 3 章、12 个主题、70 个知识点。
- 支持关键词搜索、类型筛选、章节折叠和“已掌握”进度保存。
- 18 道通关自测，每章 6 题，含即时解析和章节正确率。
- 13 组公式速查，以及逻辑化简、电路分析、器件设计、冒险排查四类流程。
- 5 份原始笔记与课堂图片，可点击放大。
- 离线 KaTeX 公式渲染，支持桌面、手机和打印布局。

## 查看

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\view.ps1
```

默认地址：`http://127.0.0.1:8770/`

整个目录可以作为静态网站部署到 GitHub Pages、Cloudflare Pages 或其他托管服务。
