# 数学物理方法互动复习站

独立于模电和普通物理网站的数学物理方法复习页面，内容依据用户提供的八份笔记与课堂图片整理：

1. 复数与复变函数：表示、运算、初等函数、区域、极限与连续性。
2. 解析函数与复积分：柯西–黎曼方程、调和函数、柯西定理、柯西积分公式、泰勒与洛朗级数。
3. 奇点、留数与积分应用：孤立奇点分类、极点阶数、留数公式、留数定理和上半平面实积分。
4. 数学物理方程与定解条件：弦振动、热传导、泊松/拉普拉斯方程，初始条件及三类边界条件。

## 功能

- 4 章、12 个主题、88 个知识点。
- 搜索、类型筛选、章节折叠和“已掌握”进度保存。
- 24 道通关自测，每章 6 题，含即时解析和章节正确率。
- 17 组公式速查，以及解析判别、闭合积分、奇点留数、实积分四类解题流程。
- 8 份原始笔记与课堂图片，可点击放大。
- 离线 KaTeX 公式渲染，支持桌面、手机和打印布局。

## 查看

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\view.ps1
```

默认地址：`http://127.0.0.1:8769/`
