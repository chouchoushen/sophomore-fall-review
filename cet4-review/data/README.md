# CET-4 扩展词表说明

扩展词表由以下公开数据整理：

- 项目：KyleBing / english-vocabulary
- 地址：https://github.com/KyleBing/english-vocabulary
- 原始文件：`json/3-CET4-顺序.json`
- 例句文件：`full_line_jsonl/sentence/正序/四级.jsonl`
- 许可：BSD 3-Clause License

本站保留与每日百词相关的单词、音标、词性、中文释义、双语例句、情景标签和少量搭配，并生成离线文件 `js/word-bank.js`。没有完整例句的词优先使用源数据中的固定搭配；仍缺少语料的词使用按词性生成的自然语境句。许可原文保存在 `licenses/KyleBing-english-vocabulary-LICENSE.txt`。
