# 英语四级每日复习站

一个独立的 CET-4 静态学习网站，包含：

1. 每日轮换的约 200 词原创英文文章，巩固四级高频词汇。
2. 46 个高频词卡，展示释义、近义词、形近词、词形拓展和双语例句。
3. 2022–2025 四年真题主题改编题库，含阅读、听力、答案详解和听力原文。
4. 浏览器语音朗读文章、单词例句和听力对话。
5. 词卡掌握进度保存在本地。

## 版权说明

历年考试真题的整篇阅读与听力内容可能受版权保护。本站在近年四级常见主题基础上重新编写文章、题目、选项、解析和听力稿，不整篇复制原试卷。

## 查看

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\view.ps1
```

默认地址：`http://127.0.0.1:8772/`

整个目录可直接部署为静态网站。
