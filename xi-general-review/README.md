# 习概导论互动复习站

根据课程课件整理的“习近平新时代中国特色社会主义思想概论”导论复习站。

## 内容结构

一个大标题：导论。

五个小标题：

1. 时代背景：为什么创立这一思想？
2. 理论根据：这一思想从哪里来？
3. 科学体系：这一思想是什么？
4. 历史地位：这一思想有何重大意义？
5. 根本保证：如何确保思想贯彻？

“实践路径”部分未收录。

## 功能

- 知识卡按概念、结构、判断、意义、要求和易错提醒分类。
- 支持关键词搜索、类型筛选、章节折叠和“已掌握”进度保存。
- 桌面、手机和打印布局均可使用。
- 全部内容为静态文本，不依赖外部服务。
