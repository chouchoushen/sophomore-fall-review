# 习概互动复习站

根据课程课件整理的“习近平新时代中国特色社会主义思想概论”复习站。

## 内容结构

当前包含导论和“新时代坚持和发展中国特色社会主义”两部分。

### 导论

五个小标题：

1. 时代背景：为什么创立这一思想？
2. 理论根据：这一思想从哪里来？
3. 科学体系：这一思想是什么？
4. 历史地位：这一思想有何重大意义？
5. 根本保证：如何确保思想贯彻？

“实践路径”部分未收录。

### 新时代坚持和发展中国特色社会主义

按课堂图片中的三节、九个小标题整理：

1. 中国特色社会主义是历史和人民的选择
2. 中国特色社会主义是社会主义而不是其他什么主义
3. 坚定道路自信、理论自信、制度自信、文化自信
4. 新时代是我国发展新的历史方位
5. 社会主要矛盾变化是关系全局的历史性变化
6. 新时代伟大变革及其里程碑意义
7. 全面贯彻党的基本理论、基本路线、基本方略
8. 统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局
9. 推动中国特色社会主义不断开拓前进

九个小标题均已配对应课堂图片，正文把图片内容整理为可搜索知识卡。

## 功能

- 知识卡按概念、结构、判断、意义、要求和易错提醒分类。
- 支持关键词搜索、类型筛选、章节折叠和“已掌握”进度保存。
- 课堂图片随对应小标题展示，可点击放大查看。
- 桌面、手机和打印布局均可使用。
- 全部内容为静态文本，不依赖外部服务。
